# Agentic RAG Assistant 项目架构说明

## 项目简介

本项目是一个结合大语言模型、工具调用、个人知识库检索和多轮记忆的 AI Agent 应用。

用户提出问题后，Agent 会判断是直接回答，还是调用知识库工具。知识库工具从本地 FAISS 向量数据库中检索相关文档，再由大语言模型根据检索结果生成回答。

## 项目主要模块

### 1. main.py

项目程序入口，负责：

- 创建 Agent 对象
- 接收用户输入
- 调用 Agent
- 输出回答
- 维持命令行对话循环

### 2. agent.py

Agent 的核心调度模块，负责：

- 接收用户问题
- 调用大语言模型
- 判断模型是否请求工具调用
- 执行工具
- 将工具结果重新交给模型
- 生成最终回答

### 3. client.py

大语言模型客户端初始化模块，负责：

- 读取 config.toml
- 获取模型提供商
- 获取模型名称
- 获取 API Key 和 base_url
- 创建模型客户端

### 4. tools.py

Agent 工具定义模块。

目前主要工具是 search_knowledge，负责接收查询内容并调用本地知识库。

### 5. knowledge_base.py

知识库检索模块，负责：

- 加载 Embedding 模型
- 加载 FAISS 索引
- 将用户问题转换成向量
- 检索相似文档
- 返回文档内容
- 返回文件来源和 PDF 页码
- 返回 FAISS 距离分数

### 6. embedding.py

Embedding 模型封装模块，负责将文本转换成向量。

知识库构建和查询时必须使用相同的 Embedding 模型。

### 7. build_index.py

知识库索引构建模块，负责：

- 读取 data/knowledge 目录中的文件
- 加载 PDF、Markdown 和 TXT
- 切分长文本
- 生成文本向量
- 创建 FAISS 向量数据库
- 将索引保存到 faiss_index

添加或删除知识库文件后，需要重新运行：

    python build_index.py

### 8. memory.py

多轮对话记忆模块，负责：

- 保存用户消息
- 保存助手回答
- 向 Agent 提供历史对话
- 支持连续追问

### 9. prompt.py

系统提示词模块，负责定义：

- Agent 的角色
- 什么时候调用知识库
- 回答时遵守的规则
- 如何减少模型幻觉
- 是否要求列出资料来源

### 10. config.toml

项目配置文件，负责管理：

- 模型提供商
- 模型名称
- API 地址
- API Key
- Embedding 模型路径
- 知识库目录
- FAISS 索引目录
- Top-K
- Chunk 大小和重叠长度

### 11. data/knowledge

个人知识库原始文档目录。

可以存放：

- PDF
- Markdown
- TXT
- 学习笔记
- 项目说明
- 技术资料

### 12. faiss_index

FAISS 本地向量索引目录，通常包含：

- index.faiss
- index.pkl

## 模块调用关系

    main.py
       ↓
    agent.py
       ↓
    client.py
       ↓
    大语言模型 API

    agent.py
       ↓
    tools.py
       ↓
    knowledge_base.py
       ↓
    FAISS 向量数据库

    build_index.py
       ↓
    data/knowledge
       ↓
    文本切分和 Embedding
       ↓
    faiss_index

## 项目核心技术

- Python
- 大语言模型 API
- Tool Calling
- LangChain
- HuggingFace Embeddings
- BGE 中文向量模型
- FAISS
- RAG 检索增强生成
- 多轮对话记忆
- TOML 配置管理

## 总结

这个 Agent 项目的主要模块包括 main.py、agent.py、client.py、tools.py、knowledge_base.py、embedding.py、build_index.py、memory.py、prompt.py 和 config.toml。

其中 agent.py 是调度中心，tools.py 提供工具，knowledge_base.py 负责检索，build_index.py 负责建立知识库，memory.py 负责保存对话历史。
