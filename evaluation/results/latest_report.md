**模型回答：**

RAG（检索增强生成）项目的用途是：**让大模型依据本地资料回答问题**，从而降低模型脱离事实“凭空回答”或产生幻觉的概率。

基本流程如下：

1. **加载文档**  
   导入本地资料，例如 PDF、Markdown 等文件。

2. **文档切分**  
   将长文档拆成较小的内容片段（Chunk），便于后续精确检索。

3. **向量化与存储**  
   为每个片段生成向量（Embedding），并存入向量数据库。

4. **检索相关内容**  
   用户提出问题后，将问题也转为向量，从向量库中检索最相关的若干片段（Top-k）。

5. **结合资料生成回答**  
   将检索到的片段连同用户问题一起交给大模型，由模型基于这些资料生成回答。

简而言之：**先从知识库找资料，再让大模型根据资料作答。**
